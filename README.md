# WPA Desk

A training environment for aspiring and new Writing Program Administrators,
built on a program model that can grow into a planning tool for working WPAs.

Training mode puts you at the desk of a fictional writing program: memos,
staffing gaps, budget pressure, and stakeholders with their own priorities.
The same tools you use to respond (cap/cost calculator, staffing planner,
stakeholder map) are the ones a working WPA would use on real data.

Status: design phase. See [docs/DESIGN.md](docs/DESIGN.md).
